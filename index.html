Google Sheet Setup Instructions

10-minute setup for permanent cloud sync & instant emails

Required Google Sheet Columns

Create a new spreadsheet at sheets.new named Daily Expenses with these 11 exact columns in Row 1:

Timestamp, Date, Category, Description, Amount, Payment Method, Vendor, Notes, Receipt, Month, Year
  1. Open Apps Script: In your Google Sheet, click Extensions → Apps Script.
  2. Paste Backend Code: Clear any code in Code.gs, open this project's google-apps-script/Code.gs file, and paste the entire code.
  3. Run Auto-Setup: Select function setupSheet in the Apps Script toolbar and click ▶ Run to automatically create and style the headers!
  4. Deploy as Web App: Click Deploy → New deployment.
    • Select type: Web app
    • Execute as: Me (your email)
    • Who has access: Anyone
  5. Copy Web App URL: Copy the deployed Web App URL (starts with https://script.google.com/macros/s/.../exec).
  6. Paste in Settings: Open Settings in this web app, paste the URL, Sheet ID, and your email, then click Test Connection and Save!
  7. Schedule Daily Digest (Optional): In Apps Script, run function createDailySummaryTrigger to receive automatic 9:00 PM email summaries daily.
